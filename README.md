# 💰 Expense Tracker

A simple and user-friendly **Expense Tracker Web Application** developed as a mini web development project. The application helps users record, manage, and monitor their daily income and expenses through an easy-to-use interface.

## 📌 Project Description

The **Expense Tracker** is a web-based application designed to help users keep track of their financial activities. Users can add income and expenses, view transaction history, and monitor their remaining balance.

This project demonstrates basic concepts of **HTML, CSS, and JavaScript**, including form handling, DOM manipulation, calculations, and browser-based data storage.

## 🎯 Objectives

* Track daily income and expenses.
* Calculate total income automatically.
* Calculate total expenses automatically.
* Display the current balance.
* Maintain a transaction history.
* Provide a simple and responsive user interface.
* Store transaction data using browser local storage.

## ⚙️ How It Works

1. Open the Expense Tracker website.
2. Enter the transaction description.
3. Enter the amount.
4. Select whether the transaction is **Income** or **Expense**.
5. Click the **Add Transaction** button.
6. The transaction will appear in the transaction history.
7. The application automatically updates:

   * Total Income
   * Total Expenses
   * Current Balance
8. Users can delete transactions when required.
9. Transaction information is stored in the browser using Local Storage.

## 🚀 How to Run the Project

### Method 1 – Using a Browser

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The Expense Tracker will open in your web browser.

### Method 2 – Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Install the **Live Server** extension if required.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## 📊 Main Calculations

The application calculates the balance using:

```text
Balance = Total Income - Total Expenses
```

For example:

```text
Income:   ₹10,000
Expenses: ₹4,500
------------------
Balance:  ₹5,500
```

## 💾 Data Storage

The project uses **Browser Local Storage** to save transactions.

This allows the transaction data to remain available even after refreshing or reopening the webpage on the same browser.
